# Nur Quran — mobile app (Expo / React Native)

A standalone Quran app in the spirit of Noor Quran: read the Quran with a
translation, listen to recitation, save bookmarks, resume where you left off,
see prayer times + Qibla, and receive an **hourly verse notification in Malay**.

Built with **Expo (SDK 54) + React Native**. It has no backend of its own — all
content comes from two free, key-less public APIs, so you can run it immediately.

## Features (v1)

| Feature | Where | Notes |
| --- | --- | --- |
| Read Quran (Arabic + translation) | `screens/ReaderScreen.js` | Uthmani script + selectable translation (Malay default) |
| Browse & search surahs | `screens/SurahListScreen.js` | All 114 surahs, search by name/number |
| Audio recitation | `context/PlayerContext.js`, `components/MiniPlayer.js` | Per-ayah or whole-surah with auto-advance, background audio, mini-player |
| Bookmarks | `screens/BookmarksScreen.js` | Save any ayah, tap to jump back to it |
| Continue reading (last-read) | `screens/HomeScreen.js` | Resume the last surah/ayah |
| Prayer times | `screens/PrayerTimesScreen.js` | Device location (fallback: Kuala Lumpur), Malay labels |
| Qibla compass | `screens/PrayerTimesScreen.js` | Bearing + live magnetometer needle |
| **Hourly Malay verse** | `lib/notifications.js`, `screens/SettingsScreen.js` | Toggle in Settings → a verse + Malay translation every hour; tap to open & listen |

## Data sources

- **[AlQuran Cloud](https://alquran.cloud/api)** — surahs, ayah text, translations
  (`ms.basmeih` = Malay), and per-ayah audio editions (`ar.alafasy`, …).
- **[AlAdhan](https://aladhan.com/prayer-times-api)** — prayer times + Qibla direction.

Both are free and require no API key. A tiny in-memory cache (`lib/api.js`) avoids
re-fetching a surah you flip back to.

## Run it

```bash
cd quran-mobile
npm install
# (optional) re-align native module versions to your installed Expo SDK:
npx expo install expo-av expo-location expo-sensors expo-notifications
npm start           # then scan the QR with Expo Go, or press i / a / w
```

- **Expo Go** is enough for reading, audio, bookmarks, prayer times and Qibla.
- **Notifications** (the hourly verse) need a **development build** to be fully
  reliable — Expo Go has limited notification support on recent SDKs:
  ```bash
  npx expo install expo-dev-client
  npx eas build --profile development --platform android   # or ios
  ```

The placeholder app icon/splash are solid-emerald PNGs generated by
`scripts/make-icons.mjs` — replace `assets/*.png` with real artwork before shipping.

## Architecture

```
quran-mobile/
├─ App.js                     ← providers + bottom-tab/stack navigation + mini-player
├─ app.json                   ← Expo config (bundle ids, plugins, permissions)
├─ src/
│  ├─ theme.js                ← design tokens + light/dark palette (useColors)
│  ├─ lib/
│  │  ├─ api.js               ← AlQuran Cloud + AlAdhan data layer
│  │  ├─ storage.js           ← AsyncStorage: settings, last-read, bookmarks
│  │  ├─ location.js          ← device coords with graceful fallback
│  │  └─ notifications.js     ← hourly verse scheduling (rolling window)
│  ├─ context/
│  │  ├─ SettingsContext.js   ← persisted preferences
│  │  └─ PlayerContext.js     ← single expo-av Sound + play queue
│  ├─ components/             ← Screen, SurahCard, AyahRow, MiniPlayer
│  └─ screens/                ← Home, SurahList, Reader, Bookmarks, PrayerTimes, Settings
```

### How the hourly Malay verse works

Local notifications carry fixed content, so `scheduleHourlyVerses()` pre-schedules
the next 12 hours — each notification is a real ayah with its Malay translation in
the body. The window is re-armed whenever you toggle it on or change translation.
Tapping a notification deep-links into the reader at that ayah (`App.js` →
`onNotificationTap`), where you can play the recitation.

> For a true always-updating home-screen widget with audio, you'd add a native
> widget (Android App Widget / iOS WidgetKit) via a config plugin or dev build.
> The hourly notification is the Expo-managed equivalent and covers the same
> "a verse every hour, in Malay, one tap to listen" intent.
